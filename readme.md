# @fishy/ui

Shared React components and Fishy design tokens for FishyStream and FishyFiles.

## Install

```sh
bun add https://github.com/FishyServices/fishy-ui.git
```

Import the component API and the Tailwind source stylesheet from the package:

```tsx
import { Button } from "@fishy/ui";
import "@fishy/ui/theme.css";
```

```sh
bun update @fishy/ui
```
